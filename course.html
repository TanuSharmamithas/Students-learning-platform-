Lesson 1: Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the basic structure of a webpage.

What can HTML create?

  • Headings
  • Paragraphs
  • Images
  • Links
  • Buttons
  • Forms

Basic HTML Example

<!DOCTYPE html>

<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>

    <p>Welcome to my website.</p>

</body>

</html>

💡 Remember

HTML provides the structure of a website. CSS is used for design, and JavaScript is used for interactivity.
